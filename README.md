## 📖 Sobre o Projeto

O **EuroMilhões — Interface Gráfica** é um projeto dedicado ao desenvolvimento de uma experiência visual intuitiva e moderna, centrada no universo de um dos jogos de lotaria mais conhecidos da Europa.

A aplicação procura combinar simplicidade de utilização, organização visual e uma apresentação cuidada, proporcionando uma experiência acessível tanto para utilizadores ocasionais como para entusiastas.

O desenvolvimento tem como prioridade a criação de uma interface funcional, com uma estrutura clara e uma navegação agradável.

### 🎯 Objetivos

* Desenvolver uma interface gráfica moderna e intuitiva.
* Facilitar a interação do utilizador com as funcionalidades da aplicação.
* Organizar a informação de forma clara e acessível.
* Proporcionar uma experiência visual consistente.
* Criar uma base sólida para futuras melhorias e funcionalidades.

## 🤝 Contribuições

Sugestões, correções e contribuições são bem-vindas!

Se pretendes ajudar a melhorar o projeto, podes abrir uma *Issue* ou submeter um *Pull Request*.

### Processo de contribuição

1. Faz um Fork do repositório.

2. Cria uma branch para as tuas alterações:

   ```bash
   git checkout -b feature/nova-funcionalidade
   ```

3. Guarda as alterações:

   ```bash
   git commit -m "Adiciona nova funcionalidade"
   ```

4. Envia a branch para o GitHub:

   ```bash
   git push origin feature/nova-funcionalidade
   ```

5. Abre um Pull Request com uma descrição clara das alterações efetuadas.
